# 研究資料整理版 v1.0（2026-11-16）

對應研究報告　臺灣鄉鎮城市活力之多源測量：資料來源覆蓋、排名敏感度與空間異質性（v12.5，2026-11-16）

本資料夾收錄研究報告與儀表板使用的鄉鎮層級整理資料。數字、名稱與定義以研究報告為準。所有 CSV 為 UTF-8（含 BOM），以 `town_code` 串接；`town_code` 為 8 碼字串，讀檔時請勿轉成數字。

## 檔案

| 檔案 | 內容 |

| uvi_towns_v1.0_20261116.csv | 鄉鎮總表，368 列，一列一鄉鎮（主檔） |
| uvi_town_boundaries_simplified_v1.0_20261116.geojson | 368 鄉鎮簡化界線，WGS84，只供顯示，不做面積計算 |
| uvi_nnk48_v1.0_20261116.csv | 臺北市、新北市、基隆市 48 區 |
| uvi_county_activity_2020_2023_v1.0_20261116.csv | 縣市層級活動量與戶籍人口變化 |
| uvi_county_ntl_2020_2023_v1.0_20261116.csv | 縣市層級夜光與活動變化 |
| uvi_town_ntl_2023-11_raw_v1.0_20261116.csv | 2023 年 11 月夜光原始鄉鎮統計（報告 4.8 節橫斷面使用） |
| uvi_summary_*.json | 報告引用的摘要數字 |

| notebooks/ | 夜光資料處理的 Google Colab 筆記本 |

## 主檔欄位

| 欄位 | 說明 |
|---|---|
| town_code, county_name, town_name | 鄉鎮代碼與名稱 |
| population_total, area_km2 | 2023 年 11 月戶籍人口、面積（km²） |
| mean_day_activity, mean_trip_8periods | 2023 年 11 月日間活動人口 A、旅次（8 時段平均） |
| F, C_tax, C_einvoice | 活動構面、消費構面（營業稅）、消費構面（電子發票），0–100 百分位 |
| F_area | 只用每平方公里活動量的活動構面（S7 使用） |
| S1–S7 | 七個計分方案的候選分數。S1–S3、S7 有 367 區；S4–S6 只有共同 365 區，其餘留空 |
| rank365_S1–rank365_S7 | 共同 365 區重排名（1 為最高，同分取最小名次）；方案比較一律用這組 |
| rank_range_6, rank_range_7 | S1–S6、S1–S7 名次全距（中位數 40、56；最大值 170、213） |
| Q_coverage | 電子發票筆數 ÷ 營業稅筆數（報告中的 Q） |
| type4 | 活動消費四象限（以中位數切分） |
| local_I, q_BH_FDR, FDR_cluster | Queen 鄰接 LISA；FDR_cluster 為 BH-FDR 5% 下的群聚類別（367 區） |
| ntl_mean/median/p90_cf1_20、_23 | 2020、2023 年 11 月夜光平均、中位數、P90（cf_cvg ≥ 1，同一程式計算） |
| ntl_qc_flag_20, ntl_qc_flag_23 | 夜光品質旗標；非 OK 者不宜直接比較 |
| dlog_ntl_mean | log(2023 ÷ 2020) 平均夜光 |
| N20, N23, A20, A23, T20, T23 | 兩期戶籍人口、日間活動、旅次 |
| dlog_N, dlog_A, dlog_T | log(2023 ÷ 2020) |
| share_change_A, share_change_T | 占全國比例的變化率；跨期比較請用這組或名次，不宜直接相減兩期原始量 |
| F20, F23, Frank20, Frank23, dFrank | 兩期活動構面、名次與名次變化（消費資料缺 2020，故只有活動構面） |
| day_over_registered_2023 | 日間活動 ÷ 戶籍人口 |
| NNK, outer_island | 北北基 48 區、金馬澎旗標；外島跨期變化可能含推估方式改變 |

## 使用說明

- S1–S7 是候選分數，用於比較測量設定的影響，不是活力排行榜，也不代表因果或政策效果。
- 主檔中的 2023 夜光與 2020 以同一程式重算，與報告 4.8 節使用的原始統計排序相關為 0.99998；引用 2023 橫斷面數字時以報告為準。
- 鄉鎮界線經簡化（座標約 200 公尺精度），面積請使用 `area_km2`。

## 資料來源

SEGIS 電信信令人口（2020、2023 年 11 月）；內政部戶籍人口；財政部營業稅消費熱度與電子發票（2023 年度）；EOG VIIRS 月合成夜光（2020、2023 年 11 月）；內政部國土測繪中心 2023 鄉鎮界線（TOWN_MOI_1120317）。
